# ゴーゴーフーリガン (Go! Go! Hooligan)

## プロジェクト概要

**ゴーゴーフーリガン**は、フットボール（サッカー）の熱狂的なサポーター文化を題材にしたWebベースのアドベンチャーゲームです。プレイヤーは試合日までの7日間で、街を探索して仲間をスカウトし、試合当日に相手チームのサポーターを圧倒する体験を提供します。

### キャッチコピー
**「仲間との絆が、スタジアムの外での勝利を生む」**

---

## ゲームの特徴

### 1. ユニークなパラメータシステム
従来のRPGとは異なる、社会的背景を反映したパラメータ設計：

- **筋力量**: 攻撃力が上がる
- **体脂肪率**: 高い方が防御力高くなる
- **幸福度**: 低い方が強い（不満が力になる）
- **モラル**: 低い方が攻撃力が高い（道徳心が低いほど凶暴）
- **学力**: 低い方が攻撃力が高い（知識がないほど単純で強い）
- **資産**: 高い方が防御力が高い（金で武装）

### 2. 複数の勧誘ルート
同じキャラクターでも、異なるアプローチで勧誘可能：
- **愛情ルート**: チームへの愛情で勧誘
- **理屈ルート**: 論理的に説得
- **力ルート**: 圧力で強制

### 3. 複数の勝利条件
バトルの勝利方法が複数存在：
- **圧倒的勝利**: 敵全体の士気を0に（難易度: 高）
- **戦術的勝利**: 敵リーダーを無力化（難易度: 中）
- **心理的勝利**: 敵の内部分裂（難易度: 中）
- **交渉による勝利**: 戦闘回避（難易度: 低）

### 4. 高いリプレイ性
- 複数のエンディング
- 異なるチーム構成による戦略の多様性
- 複数の勧誘ルート

## 遊び方

### 1. ゲーム開始
ブラウザで`index.html`を開くか、GitHub Pagesで公開されたURLにアクセスします。

### 2. 7日間の探索
- 各日は「朝」「昼」「夜」の3時間帯に分かれています
- 昼間に街を探索し、NPCと会話して勧誘します
- 夜間にチームメンバーを確認し、作戦を立てます

### 3. キャラクター勧誘
- 各NPCには異なる説得方法があります
- 相手の背景を理解し、最適な方法を選びます
- 成功すると、チームに加わります

### 4. 試合当日
- 7日目の夜に試合当日となります
- 集めた仲間で敵チームのサポーターと対決します
- 複数の勝利条件から選択できます

### 5. エンディング
- 集めた仲間の数と戦闘結果によってエンディングが変わります
- グッドエンド、ノーマルエンド、バッドエンドが存在します

## 今後の改善予定

1. **キャラクター間の関係性**: シナジーとアンチシナジーシステム
2. **日常パートの動的イベント**: 時間経過で敵との小競り合いなど
3. **敵チームのストーリー**: 敵にも背景があり、寝返らせることも可能
4. **パラメータの動的変化**: 幸福度やモラルがゲーム進行で変化
5. **複数の勝利条件**: より詳細な戦闘システム
6. **時間制限と緊張感**: 7日間で全員を勧誘できない設計
7. **ニューゲーム+**: 2回目のプレイで新しい選択肢が解放
8. **ビジュアル強化**: キャラクター画像、背景画像の追加
